# Research integration validation

`pnpm verify:iteration` completed successfully on Node 24.15.0 after this
documentation/research integration. The [summary](./summary.json) records the
scope, exit status, report hashes and counts. The [reports](./reports) directory
retains the 19 JSON reports regenerated by that gate; their original tracked
`project/evidence` files were restored byte-for-byte to avoid replacing historical
measurements as part of a documentation change.

The gate included 329 root tests, 30 browser tests, deployment resource tests,
storage adapters, 19 external-runtime tests, coverage, local packaging, bounded
performance/capacity, both Compose profiles, Helm and OIDC. All recorded test
reports passed. Source hashes, local links/anchors, 33 uncertainty-to-task
mappings, 27 task definitions, 260 conformance test mappings, and whitespace
checks also passed. Only GIT-008's proof-gap text changed in the ledger; its
status, acceptance statements and every other ledger field stayed unchanged.

The local baseline emitted no investigation warning. The capacity baseline
warned that peak server RSS exceeded 512 MiB. See the
[capacity report](./reports/local-capacity-baseline.json) for the exact workload
and memory measurements. This single gate run is not a controlled performance
comparison and does not resolve the earlier Node 26.5 review's observations.

No runtime source, dependency version, production deployment or provider account
was changed. These local/container test results do not qualify all live cloud or
agent-host cases and do not close the implementation tasks in
[NEXT-STEPS.md](../../../../NEXT-STEPS.md).
